# LEICHT IA Android — mises à jour
Canal public dédié aux APK Android signées. Aucun serveur PC/RDS n'utilise ce dépôt.
Aucune clé API, conversation, mémoire, fichier personnel ou modèle n'est publié ici.
Chaque APK conserve le certificat existant et le package com.leichtia.mobile.
L'application compare le versionCode, télécharge l'APK, vérifie la taille, le SHA-256 et le certificat avant de proposer l'installation Android.
Android demande l'accord de l'utilisateur pour installer la mise à jour ; l'application conserve les conversations et les données locales.
